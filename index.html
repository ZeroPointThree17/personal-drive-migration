Personal Drive Migration

A private utility that uses rclone to copy the owner's Dropbox files into the owner's Google Drive and verify the copies.

The migration runs on an owner-controlled server. It inventories files, copies their folder structure and supported timestamps, preserves earlier migrated versions when replacements are needed, and checks file contents. Dropbox originals are not modified or deleted by the migration.

Google Drive access

The app requests permission to view and manage Drive files so it can continue working with existing migration files and verify their contents. This Google permission covers the account's Drive files; the migration is configured to write only within its dedicated destination and version folders.

Private operation

This informational website offers no public signups, uploads, file browsing, or file sharing. It does not receive migration files or OAuth credentials. Credentials, inventories, and detailed reports are kept in the owner's private migration environment.

Terms of use

This utility is for the account owner's personal use with accounts and files they are authorized to access. It is not offered as a public migration service. The owner controls the migration and may stop it or revoke its access at any time.
