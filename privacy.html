Personal Drive Migration

Privacy policy

Last updated: 24 October 2026.

Personal Drive Migration is a private utility operated for its account owner. It copies files from the owner's authorized Dropbox account to the owner's authorized Google Drive account using rclone on an owner-controlled server. It is not a service for public registration.

Data accessed and its purpose

The utility accesses account identifiers and storage quota information to confirm the authorized accounts and available space. It reads file and folder names, paths, identifiers, sizes, modification times, and available checksums to inventory, resume, and verify the migration.

File contents pass through the migration server during copying and content verification. The utility creates or updates files in its designated Google Drive destination and retains earlier migrated versions in a designated version folder when needed. Dropbox access is read-only.

Sharing metadata and connected-application information may be recorded privately to identify settings that need manual migration. The file-copy process does not recreate sharing permissions or publish sharing links.

Access, storage, and disclosure

Google authorization permits access to view and manage Drive files. The migration's configuration and checks limit writes to its designated folders. OAuth credentials and tokens are stored in private configuration files, not in this website. Private inventories, verification checkpoints, and reports are retained on the owner's server and management computer for resumability and review.

Migration data is used for the owner's requested copy, verification, and troubleshooting. It is exchanged with the authorized cloud providers and processed in the owner's migration environment. This website does not expose file contents, filenames, account details, sharing links, or credentials. The utility does not sell data, use it for advertising, or use it to train generalized artificial intelligence models.

Retention and control

Copied files and retained versions remain in the owner's Google Drive until the owner manages them. Private configuration, inventories, logs, and reports remain until the owner removes them. There is no automatic deletion schedule. The migration does not delete Dropbox originals or cancel the Dropbox account.

The owner can stop the migration and revoke Google access through Google Account connections. Revoking authorization prevents future authorized API access; it does not delete files already copied or erase locally retained migration records. Account and data-management requests are handled directly by the owner; this site has no public account or support-request system.

Google API Limited Use

Personal Drive Migration's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

This website

These static pages contain no analytics scripts, advertising, forms, or application cookies. The hosting provider may process ordinary web request information, such as an IP address, browser details, and requested page, to serve the site. That hosting activity is separate from the private migration.
